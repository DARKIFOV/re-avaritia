# MetaTech Reborn — Forge 1.20.1

Порт механик MetaAdvanced, MetaThaumcraft, Greenhouses и связанных аддонов на Forge 1.20.1.

## Текущая ветка 0.6.0 WIP

Работа ведётся в `agent/0.5.8-luck-converters`, PR №10. Ветка сохраняет весь объём 0.5.9 и продолжает портирование экстремального молекулярного сборщика 9×9 с нативной интеграцией Applied Energistics 2.

## Молекулярный сборщик 9×9 и AE2

Реализовано:

- ручная сетка крафта 9×9;
- внутренний банк из 9 шаблонов без улучшения и 36 шаблонов с улучшением ёмкости;
- запрет снятия улучшения, пока заняты дополнительные слоты банка;
- собственный AE2-узел с каналом и публикацией внутренних шаблонов через `ICraftingProvider`;
- атомарная приёмка полного набора ингредиентов из ME-сети;
- списание AE2-входов только после успешной полной приёмки задания;
- возврат готового результата непосредственно в ME-хранилище;
- сохранение AE2-узла, инвентаря, шаблонов, энергии, прогресса и блокировки рецепта;
- безопасный запуск без AE2: интеграция регистрируется только при наличии мода.

Код собирается на официальном API AE2 для Forge 1.20.1. Окончательная проверка подключения кабеля, канала, автокрафта и перезапуска мира выполняется непосредственно в Minecraft.

## Преобразователи удачи

Обычная версия:

- 30 входных и 30 выходных слотов;
- отдельный слот модуля удачи или кирки Fortune;
- 6 слотов улучшений и слот FE-предмета;
- базовый цикл 1000 тиков;
- базовый расход 100 FE/т;
- внутренний буфер 10 000 FE.

Продвинутая версия:

- 72 входных и 60 выходных слотов;
- цикл 500 тиков;
- обрабатывает по 2 блока из каждого занятого входа за цикл;
- сохраняет модуль, улучшения, FE, прогресс и весь инвентарь в NBT.

Возвращены 12 уровней модулей удачи: `1, 2, 3, 5, 10, 15, 20, 25, 30, 35, 40, 50`, а также улучшения скорости, эффективности, числа операций, удвоения, переплавки и автоматического вывода. Fortune применяется через современные loot tables, переплавка — через RecipeManager. Перед расходованием входов проверяется вместимость всего выходного буфера.

## Остальные восстановленные системы

- объединитель нейтрония с 9 независимыми процессами и 40 выходными слотами;
- энергетическая еда I–IV с Forge Energy;
- теплица Botania и модули;
- многоблочный мана-бур;
- терминал кодирования экстремальных шаблонов.

## Ресурсы

Повреждённые base64-фрагменты 0.5.9 больше не используются при сборке. В ветку возвращён цельный проверяемый архив базовых текстур, а модели, блокстейты, лут-таблицы и рецепты новых машин и предметов хранятся обычными файлами ресурсов.

## Проверка

```bash
gradle build
```

GitHub Actions проверяет текущий head PR №10 и формирует единый JAR. Успешная сборка подтверждает компиляцию и упаковку; игровые механики и GUI дополнительно проверяются в Minecraft 1.20.1.

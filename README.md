# MetaTech Reborn — Forge 1.20.1

Порт механик MetaAdvanced, MetaThaumcraft, Greenhouses и связанных аддонов на Minecraft 1.20.1 Forge.

## Текущая разработка

- ветка: `agent/0.6.0-molecular-assembler`;
- PR: №11;
- версия: `0.6.0-molecular-assembler-WIP`;
- Minecraft 1.20.1;
- Forge 47.4.22;
- Java 17;
- AE2 15.x является обязательной зависимостью.

## Основа молекулярного сборщика

Для восстановления использованы файлы из переданного пользователем архива `мета(3).zip`:

- `LoliEnergistics-1.7.10-client.jar`;
- `MetaAdvanced-1.0.0-client.jar`;
- изменённый старый `AE2-client.jar`;
- конфигурация MetaAdvanced.

В MetaAdvanced найдены настоящие классы экстремальной системы:

- `TileAE2AvaritiaExtremeAssembler`;
- `TileAE2AvaritiaExtremeMultiAssembler`;
- `TileAE2AvaritiaExtremeEncoder`;
- `RecipeHelperAE2AvaritiaExtreme`;
- базовые классы многозадачного сборщика и терминала.

В предоставленных client-JAR серверные методы приёма задания, обработки и кодирования заменены заглушками. Поэтому структура, слоты, поля NBT, конфигурация и клиентское поведение перенесены из оригинала, а отсутствующая серверная часть безопасно восстановлена под официальный API AE2 15.x. Это не выдаётся за дословное копирование отсутствующего кода.

## Экстремальный молекулярный сборщик 9×9

Реализовано:

- полная сетка рецепта 9×9 — 81 позиция;
- прямой узел AE2 с каналом и энергопотреблением сети;
- машина одновременно работает как `ICraftingProvider` и `ICraftingMachine`;
- внутренние шаблоны публикуются непосредственно в ME-сеть;
- один шаблон хранит точную раскладку 81 позиции, результат и NBT предметов;
- 9 слотов шаблонов без расширения;
- расширение добавляет 27 слотов;
- итоговая ёмкость: **9 + 27 = 36 шаблонов**;
- расширение нельзя снять, пока дополнительные слоты заняты;
- пять настоящих слотов карт скорости AE2;
- скорость и расход энергии масштабируются по таблице молекулярного сборщика AE2 1.20.1;
- исходные значения MetaAdvanced: 24 тика и 100 энергии за тик;
- до 64 параллельных заданий;
- машина принимает следующие задания, пока очередь не заполнена, как старый многозадачный сборщик;
- атомарная приёмка полного комплекта ингредиентов — частично принятое задание невозможно;
- каждое задание повторно проверяется серверным RecipeManager;
- поддерживаются рецепты Re-Avaritia и собственные рецепты датапака;
- результаты, вёдра, формы и остальные контейнеры возвращаются в ME-сеть;
- AE2 получает сведения о возвращаемых контейнерах ещё на этапе планирования;
- отдельный постоянный буфер результата и возврата ингредиентов;
- при исчезновении или изменении рецепта все ингредиенты возвращаются в ME-сеть;
- заполненная либо отключённая ME-сеть не удаляет результат и не создаёт копии;
- готовое задание не расходует FE повторно, пока ожидает свободное место;
- очередь, входы, прогресс, ожидаемый результат, энергия и узел AE2 сохраняются в NBT;
- задания продолжаются после перезапуска мира и повторной загрузки чанка;
- при разрушении блока выпадают шаблоны, карты скорости, буфер и ингредиенты незавершённых заданий;
- ручной режим через видимую сетку 9×9 сохранён.

## Терминал шаблонов 9×9

- 81 позиция является призрачной сеткой, как в терминалах AE2;
- предметы для задания рецепта не расходуются;
- призрачные предметы не выпадают при разрушении блока;
- поддерживаются обычный щелчок, назначение из панели быстрого доступа и очистка;
- пустой шаблон расходуется только после успешной серверной проверки рецепта;
- готовый шаблон нельзя перезаписать, пока он не забран;
- результат определяется через RecipeManager Re-Avaritia или рецепт MetaTech;
- раскладка и результат сохраняются в NBT шаблона.

## Закрытые дыры

- нет частичного списания входов при отклонённом задании;
- нет дюпа через реальные предметы в сетке терминала;
- нет потери результата при заполнении ME-хранилища;
- нет повторного расхода энергии у уже законченного задания;
- нет извлечения ингредиентов автоматизацией из активной сетки;
- нет снятия расширения с занятыми скрытыми слотами;
- нет подмены результата после изменения рецепта;
- нет потери ингредиентов при удалении рецепта или разрушении машины;
- сетевой вывод использует `IActionSource.ofMachine`, поэтому учитываются безопасность и аудит AE2.

## Остальные системы мода

В одном JAR также остаются:

- теплица Botania и модули;
- многоблочный мана-бур и улучшения;
- объединитель нейтрония;
- энергетическая еда I–IV;
- обычный и продвинутый преобразователи удачи;
- 12 уровней модулей удачи;
- улучшения скорости, эффективности, операций, удвоения, переплавки и автовывода.

Для восстановленных блоков и предметов генерируются модели, текстуры, loot tables и рецепты. Русская и английская локализации включаются в итоговый JAR.

## Сборка и проверка

```bash
gradle build
```

GitHub Actions проверяет PR №11. Успешная компиляция подтверждает формирование JAR, но не заменяет проверку непосредственно в Minecraft.

Перед признанием версии стабильной проверяются:

- появление всех 36 шаблонов в GUI;
- публикация рецептов в терминале автокрафта AE2;
- несколько одновременных заказов;
- все пять карт скорости;
- перезапуск мира во время работы;
- отключение кабеля и заполнение ME-хранилища;
- удаление рецепта во время задания;
- возврат контейнеров;
- отсутствие расхода и дюпа предметов в призрачной сетке терминала.

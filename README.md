# MetaTech Reborn — Forge 1.20.1

Порт машин и предметов MetaAdvanced, MetaThaumcraft, Greenhouses и связанных аддонов на Minecraft 1.20.1 Forge.

## Текущая ветка

- ветка: `agent/0.5.8-luck-converters`;
- PR: [#10](https://github.com/DARKIFOV/re-avaritia/pull/10);
- версия: `0.5.8-runtime-repair-WIP`;
- один игровой JAR;
- GitHub Actions №450: `BUILD SUCCESSFUL`.

## Исправления после проверки в Minecraft

### Теплица Botania

- интерфейс перестроен без наложения подписей и слотов;
- отображаются конкретные причины остановки;
- воду и лаву можно заливать ведром, Forge-контейнером или трубой;
- добавлены резервные рецепты на случай сбоя датапака;
- поддерживаются Endoflame, Hydroangeas, Gourmaryllis, Entropinnyum, Thermalily и Spectrolus;
- работают Economy I–III, Efficiency I–III, Speed I–III, Infinite Day, Infinite Night и Infinite Lava.

### Мана-бур

- принимает ману лучами Mana Spreader и через Spark;
- забирает ману из обычного соседнего Mana Pool, а не только из бассейна в режиме отдачи;
- приём маны работает во время сборки структуры;
- добавлен резервный рецепт добычи, если JSON-рецепт отсутствует;
- GUI сообщает: не собрана структура, нет модуля, нет рецепта, нет маны, заполнен выход или идёт добыча;
- улучшения: скорость I–V, добыча I–IX, генерация I–III.

### Экстремальный молекулярный сборщик 9×9

- добавлен отдельный слот FE-аккумулятора;
- сохраняется питание кабелем Forge Energy;
- внешняя автоматизация больше не извлекает ингредиенты из сетки рецепта;
- банк шаблонов отображается без наложения текста;
- GUI показывает отсутствие рецепта, FE, заполненный выход, работу и готовность к заданию AE2;
- 9 слотов доступны без расширения;
- расширение добавляет 27 слотов;
- итог: **9 + 27 = 36 шаблонов**.

### Терминал шаблонов 9×9

- отдельные кнопки кодирования и очистки;
- один шаблон хранит все 81 позиции и результат в NBT;
- добавлена полная русская и английская локализация сообщений;
- сырые ключи `gui.metatech_reborn.*` больше не должны отображаться.

## Следующий перенос

По требованию пользователя в проект должны входить и не считаются отменёнными:

- объединитель нейтрония;
- энергетическая еда;
- преобразователь удачи;
- продвинутый преобразователь удачи;
- уровневые модули удачи.

Они будут выпускаться только после восстановления механик, GUI и проверки сборки. Ветророторы, ME-импорт/экспорт маны, снежная пушка и топор черепов в актуальный объём не входят.

## Сборка

```bash
gradle build
```

Успешная компиляция не заменяет проверку непосредственно в Minecraft. Для отчёта об ошибке приложите `logs/latest.log` после запуска актуального JAR.

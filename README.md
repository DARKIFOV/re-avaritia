# MetaTech Reborn — Forge 1.20.1

Перенос механик `MetaAdvanced` с Minecraft 1.7.10 на Forge 1.20.1.

## Реализовано

### Молекулярный сборщик 9x9

- прямое чтение рецептов Re-Avaritia из `ModRecipeTypes.CRAFTING_TABLE_RECIPE`;
- shaped и shapeless-рецепты через публичный `ITierCraftingRecipe` API;
- собственный datapack recipe type `metatech_reborn:molecular_assembling`;
- сетка 9x9, выходной слот, FE-буфер и прогресс;
- фиксация раскладки рецепта для AE2 Pattern Provider;
- `IItemHandler`, автоматический вывод и NBT-сохранение;
- русский и английский языки;
- JEI-категория.

### Объединитель нейтрония

Модуль перенесён по поведению старого `TileElectricNeutronCombiner`:

- девять нейтронных сборщиков устанавливаются в девять независимых входов;
- сборщики работают как постоянные модули и не расходуются;
- каждый вход имеет собственный прогресс;
- готовые ресурсы складываются в выходной буфер на 40 слотов;
- машина принимает Forge Energy;
- поддерживаются трубы и другие системы через `IItemHandler`;
- доступен автоматический вывод в соседний инвентарь;
- состояние всех девяти процессов, энергия и инвентарь сохраняются через NBT;
- соответствия «сборщик → результат» задаются JSON-рецептами `metatech_reborn:neutronium_combining`;
- добавлена JEI-категория.

Встроены рецепты для:

- `avaritia:neutron_collector` → `avaritia:neutron_pile`;
- `avaritia:dense_neutron_collector` → `avaritia:neutron_nugget`;
- `avaritia:denser_neutron_collector` → `avaritia:neutron_ingot`;
- `avaritia:densest_neutron_collector` → `avaritia:neutron_ingot` с ускоренной обработкой.

## Как работает AE2

1. Разложите рецепт в сетке 9x9.
2. Сборщик найдёт и зафиксирует рецепт.
3. После крафта шаблон позиций сохранится.
4. Подключите AE2 Pattern Provider к любой стороне блока.
5. Каждый вход принимает только предмет своей позиции шаблона.
6. Кнопка **«Снять фиксацию»** позволяет заменить рецепт.

## Требования

- Minecraft 1.20.1
- Forge 47.4.22
- Java 17
- Re-Avaritia 1.4.1 — необязательно, но требуется для её рецептов
- Applied Energistics 2 15.x — необязательно
- JEI 15.20.0.112 — необязательно

## Сборка

```bash
gradle build
```

Готовый JAR появляется в `build/libs/`.

## Конфиг

После первого запуска создаётся `config/metatech_reborn-common.toml`. В нём настраиваются:

- интеграция Re-Avaritia;
- ёмкость и приём FE молекулярного сборщика;
- время и FE/t рецептов Re-Avaritia;
- автоматический вывод;
- ёмкость и приём FE объединителя нейтрония.

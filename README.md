# MetaTech Reborn — Forge 1.20.1

Перенос механик `MetaAdvanced`, `MetaThaumcraft` и `Greenhouses` с Minecraft 1.7.10 на Forge 1.20.1.

## Реализовано

### Молекулярный сборщик 9x9

- прямое чтение рецептов Re-Avaritia из `ModRecipeTypes.CRAFTING_TABLE_RECIPE`;
- shaped и shapeless-рецепты через публичный `ITierCraftingRecipe` API;
- собственный datapack recipe type `metatech_reborn:molecular_assembling`;
- сетка 9x9, выходной слот, FE-буфер и прогресс;
- фиксация раскладки рецепта для AE2 Pattern Provider;
- `IItemHandler`, автоматический вывод и NBT-сохранение;
- русский и английский языки.

### Объединитель нейтрония

Модуль перенесён по поведению старого `TileElectricNeutronCombiner`:

- девять нейтронных сборщиков устанавливаются в девять независимых входов;
- сборщики работают как постоянные модули и не расходуются;
- каждый вход имеет собственный прогресс;
- готовые ресурсы складываются в выходной буфер на 40 слотов;
- машина принимает Forge Energy;
- поддерживаются трубы и автоматический вывод;
- рецепты задаются JSON типом `metatech_reborn:neutronium_combining`.

### Мана-бур Botania

MVP3 воссоздаёт оригинальную модульную механику `MetaThaumcraft`, а не обычный карьер:

- внутренний буфер Botania-маны;
- приём маны от всплесков Botania;
- управляемое подтягивание маны из соседних Mana Pool, переведённых в режим выдачи;
- слот модуля добычи;
- улучшения скорости, добычи и генерации с пределами 5/9/3 как в старой конфигурации;
- 27 выходных слотов, `IItemHandler`, автоматический вывод и NBT-сохранение;
- настраиваемые datapack-рецепты `metatech_reborn:mana_drill_generating`;
- встроенный модуль добычи ресурсов обычного мира.

Пример рецепта мана-бура:

```json
{
  "type": "metatech_reborn:mana_drill_generating",
  "module": { "item": "metatech_reborn:mana_drill_module" },
  "mana_cost": 50000,
  "time": 200,
  "drops": [
    { "item": "minecraft:raw_iron", "min": 2, "max": 6, "chance": 10000 }
  ]
}
```

`chance` задаётся в десятитысячных долях: `10000` = 100%, `500` = 5%.

## Требования

- Minecraft 1.20.1
- Forge 47.4.22
- Java 17
- Botania 1.20.1-454 или новее
- Re-Avaritia 1.4.1 — необязательно, но требуется для её рецептов и рецептов машин
- Applied Energistics 2 15.x — необязательно
- JEI 15.x — необязательно

## Сборка

```bash
gradle build
```

Готовый JAR появляется в `build/libs/`.

## Конфиг

После первого запуска создаётся `config/metatech_reborn-common.toml`. Настраиваются энергия машин, скорость рецептов, автоматический вывод, ёмкость мана-бура, радиус и период поиска бассейнов маны, скорость передачи маны и пределы улучшений.

## Статус переноса

Текущая версия: **0.3.0-mvp3**.

Готовы:

- MVP1 — молекулярный сборщик 9x9;
- MVP2 — объединитель нейтрония;
- MVP3 — мана-бур Botania.

Следующая очередь: теплицы Botania из `MetaThaumcraft`/`Greenhouses`, затем сборщики 3x3, 5x5 и 7x7.

`ExtremeAutoCrafter` является отдельным модом и в этот перенос не включён.

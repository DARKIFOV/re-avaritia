# MetaTech Reborn — Forge 1.20.1

Порт на Minecraft 1.20.1 Forge только тех систем, которые запросил пользователь.

## Точный объём проекта

В итоговый мод должны входить только:

1. **Теплица Botania**
   - рабочая машина;
   - слот цветка;
   - 3 слота модулей;
   - 6 слотов топлива;
   - бак воды/лавы;
   - буфер и вывод маны;
   - Endoflame, Hydroangeas, Gourmaryllis, Entropinnyum, Thermalily и Spectrolus;
   - модули Economy, Efficiency, Speed, Infinite Day, Infinite Night и Infinite Lava.

2. **Мана-бур**
   - многоблочная структура;
   - приём маны Botania;
   - добыча;
   - улучшения скорости I–V, добычи I–IX и генерации I–III;
   - выбранные пользователем текстуры.

3. **ME-импорт и ME-экспорт маны**
   - два отдельных блока/устройства для сети Applied Energistics 2;
   - импорт маны из Botania в ME-сеть;
   - экспорт маны из ME-сети в Botania;
   - буфер, скорость передачи, канал/питание AE2, GUI и диагностика.

4. **Экстремальный молекулярный сборщик 9×9**
   - прямая интеграция с AE2 Pattern Provider;
   - рецепты 9×9;
   - возврат результата в сеть AE2;
   - один JAR без внешнего аддона.

5. **Шаблоны и улучшения сборщика**
   - пустой шаблон 9×9;
   - закодированный шаблон 9×9;
   - терминал кодирования;
   - 9 слотов шаблонов по умолчанию;
   - улучшение добавляет 27 слотов;
   - итоговая ёмкость — **36 шаблонов**;
   - улучшения скорости, энергоэффективности и ёмкости, если они относятся к экстремальному сборщику.

## Что не входит в проект

Следующие ранее добавленные вещи не относятся к текущему заказу и должны быть удалены из итоговой сборки:

- объединитель нейтрония;
- мета-ваджра;
- снежная пушка;
- топор черепов;
- электрические мечи;
- энергетическая еда;
- ветророторы;
- любые другие предметы и машины, не перечисленные в разделе «Точный объём проекта».

Часть этого старого кода пока ещё находится в рабочей ветке как наследие предыдущих этапов. Следующий этап — очистить регистрации, рецепты, модели, локализацию и ресурсы, чтобы они не попадали в новый игровой JAR.

## Текстуры теплицы

Выбран **четвёртый вариант**:

- тёмный livingrock;
- усиленные металлические панели;
- бронзовые и деревянные крепления;
- бирюзовые мана-линии;
- мох и растительность;
- стеклянная камера;
- отдельный мана-порт.

## Текстуры мана-бура

Используется выбранный пользователем вариант:

- livingrock-серый корпус;
- livingwood/бронзовые крепления;
- бирюзовые мана-линии;
- зелёно-бирюзовое ядро;
- фиолетовые иконки модуля и улучшений.

- удаления лишних систем;
- успешной GitHub Actions сборки;
- проверки в Minecraft;
- подтверждения работы теплицы, мана-бура, ME-импорта/экспорта маны и экстремального сборщика 9×9.

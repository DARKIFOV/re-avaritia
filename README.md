# MetaTech Reborn — Forge 1.20.1

Современный порт машин из старых `MetaAdvanced`, `MetaThaumcraft` и `Greenhouses` для Minecraft 1.20.1.

## Версия 0.4.0-fixes

### Исправлены текстуры и GUI

- Все три машины получили собственные технологичные модели и пиксельные текстуры.
- Удалены ссылки на отсутствующие текстуры Botania, из-за которых блок мана-бура отображался чёрно-фиолетовым.
- GUI больше не рисуются временными сплошными прямоугольниками: добавлены отдельные фоновые текстуры, панели, рамки слотов, шкалы энергии/маны и понятная компоновка.

### Молекулярный сборщик 9×9

- Поддерживает рецепты Re-Avaritia `crafting_table_recipe`, включая shaped и shapeless.
- Имеет сетку 9×9, выход, FE, прогресс, фиксацию рецепта и безопасное NBT-сохранение.
- Реализован прямой интерфейс AE2 `ICraftingMachine`.
- Pattern Provider передаёт полный пакет ингредиентов одним запросом, а сборщик атомарно раскладывает их по зафиксированному шаблону 9×9.
- Для работы AE2 сначала один раз соберите и зафиксируйте нужный рецепт вручную, затем поставьте Pattern Provider вплотную к любой стороне машины.

### Объединитель нейтрония

Девять нейтронных сборщиков работают параллельно и не расходуются. Результаты поступают в 40 выходных слотов.

Добавлены четыре слота улучшений и три типа предметов:

- **Скорость** — до 8 штук, ускоряет все девять процессов.
- **Эффективность** — до 8 штук, уменьшает расход FE вплоть до 20% исходного.
- **Выход** — до 3 штук, умножает результат до ×4 и соответственно повышает энергозатраты.

Улучшения и инвентарь сохраняются через NBT и доступны для автоматизации через Forge Item Handler.

### Мана-бур — многоблочная структура

Одиночный блок больше не работает сам по себе. Машина активируется только при правильной структуре 3×3×3.

Контроллер является центральным блоком передней стенки среднего слоя. Структура продолжается на два блока назад относительно лицевой стороны контроллера.

Особые позиции:

- контроллер: спереди по центру среднего слоя;
- мана-ядро: непосредственно за контроллером в центре;
- сопло: над ядром;
- блок над контроллером должен оставаться воздухом;
- остальные 23 позиции — корпуса мана-бура.

Схема сбоку:

```text
Верх:     [корпус] [воздух] [корпус]
          [корпус] [сопло]  [корпус]
          [корпус] [корпус] [корпус]

Середина: [корпус] [контроллер] [корпус]
          [корпус] [ядро]       [корпус]
          [корпус] [корпус]     [корпус]

Низ:      полностью из корпусов 3×3
```

В GUI отображается состояние структуры. Пока она не собрана, добыча и расход маны остановлены.

Мана-бур сохраняет оригинальную систему уровней из конфигурации 1.7.10:

- скорость I–V;
- добыча I–IX;
- генерация I–III.

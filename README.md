# MetaTech Reborn — Forge 1.20.1

Порт машин и предметов MetaAdvanced, MetaThaumcraft, Greenhouses и связанных аддонов на Minecraft 1.20.1 Forge.

## Активная разработка

- ветка: [`agent/0.5.8-luck-converters`](https://github.com/DARKIFOV/re-avaritia/tree/agent/0.5.8-luck-converters);
- черновой PR: [#10](https://github.com/DARKIFOV/re-avaritia/pull/10);
- версия: `0.5.8-runtime-repair-WIP`;
- GitHub Actions №450: `BUILD SUCCESSFUL`;
- сборка выпускается одним JAR.

## Исправленные машины

### Теплица Botania

- GUI без наложения текста и слотов;
- понятные причины остановки;
- заливка воды и лавы ведром, Forge-контейнером или трубой;
- резервные рецепты при сбое датапака;
- Endoflame, Hydroangeas, Gourmaryllis, Entropinnyum, Thermalily и Spectrolus;
- Economy I–III, Efficiency I–III, Speed I–III, Infinite Day, Infinite Night и Infinite Lava.

### Мана-бур

- многоблочная структура 3×3×3;
- приём маны через Mana Spreader, Spark и обычный Mana Pool;
- резервный рецепт добычи;
- GUI показывает состояние структуры, модуля, рецепта, маны и выхода;
- скорость I–V, добыча I–IX, генерация I–III.

### Экстремальный молекулярный сборщик 9×9

- прямая интеграция с AE2 Pattern Provider;
- отдельный слот FE-аккумулятора и питание кабелем;
- исправленная внешняя автоматизация инвентаря;
- банк шаблонов без наложения подписей;
- 9 базовых слотов и 36 после расширения;
- один шаблон хранит полный рецепт из 81 позиции и результат.

### Терминал шаблонов

- кодирование и очистка сетки;
- пустые и закодированные шаблоны 9×9;
- русская и английская локализация;
- устранён вывод необработанных ключей `gui.metatech_reborn.*`.

## Состав, который требуется сохранить и продолжить

Следующие системы не отменены и должны быть возвращены/допортированы после проверки основных машин:

- объединитель нейтрония;
- энергетическая еда;
- преобразователь удачи;
- продвинутый преобразователь удачи;
- модули удачи.

Ветророторы, ME-импорт/экспорт маны, снежная пушка и топор черепов в текущий объём не входят.

## Зависимости

- Minecraft 1.20.1
- Forge 47.4.22
- Java 17
- Applied Energistics 2 15.4.x
- Botania 1.20.1-454+
- Re-Avaritia 1.4.1
- JEI 15.x — необязательно

## Сборка

```bash
gradle build
```

Успешная компиляция не заменяет проверку непосредственно в Minecraft. Для отчёта об ошибке приложите `logs/latest.log` и скриншот GUI.

# MetaTech Reborn — Forge 1.20.1

Современный порт машин и предметов из старых `MetaAdvanced`, `MetaThaumcraft`, `Greenhouses` и связанных аддонов для Minecraft 1.20.1 Forge.

## Текущая разработка

Рабочая ветка: `agent/0.5.5-unified-ae2`

Цель этой ветки — отказаться от отдельного JAR `AE2 Molecular Assembler Plus` и перенести необходимые механики экстремального молекулярного сборщика и терминала шаблонов непосредственно в **MetaTech Reborn**.

> Важно: ветка является экспериментальной. Компиляция и работа в игре должны быть проверены до слияния в `main`.

## Исправленное количество шаблонов

Правильный итоговый предел — **36 шаблонов**.

- без улучшения: **9** слотов шаблонов;
- улучшение ёмкости добавляет: **27** слотов;
- итог: **9 + 27 = 36** шаблонов.

Ранее упоминавшиеся пределы 28 и 30 больше не используются.

## Нативная система шаблонов 9×9

В ветке `agent/0.5.5-unified-ae2` уже добавляется собственная система MetaTech:

- пустой шаблон 9×9;
- закодированный шаблон 9×9;
- один шаблон хранит всю сетку из 81 позиции и результат;
- отдельное улучшение ёмкости до 36 шаблонов;
- внутренний банк на 36 позиций;
- первые 9 позиций доступны всегда;
- позиции 10–36 активируются улучшением;
- AE2 Pattern Provider выбирает подходящий сохранённый шаблон по результату и переданным ингредиентам;
- старый режим ручной фиксации рецепта оставлен для совместимости миров.

На следующем этапе переносится отдельный терминал кодирования с нормальной прокруткой, очисткой и перезаписью шаблонов. Код из стороннего проекта используется только в рамках его MIT-лицензии с сохранением сведений об авторстве.

## Молекулярный сборщик 9×9

- поддерживает рецепты Re-Avaritia `crafting_table_recipe`, включая shaped и shapeless;
- имеет сетку 9×9, выход, FE, прогресс и NBT-сохранение;
- реализует интерфейс AE2 `ICraftingMachine`;
- принимает задания от Pattern Provider;
- использует нативный банк шаблонов MetaTech;
- реальные затраты FE исправлены в ветке `agent/0.5.4-machine-fixes` и перенесены дальше.

## Объединитель нейтрония

- девять независимых входов;
- поддержка обычного, плотного, более плотного и максимально плотного нейтронного сборщика Re-Avaritia;
- резервные рецепты при сбое загрузки датапака;
- приём FE кабелями и заряженными предметами;
- отдельные индикаторы состояния каждого процесса;
- улучшения скорости, энергоэффективности и выхода.

## Мана-бур

Многоблочная структура 3×3×3:

- контроллер расположен в центре внешней стенки;
- ядро находится за контроллером;
- сопло находится над ядром;
- блок над контроллером должен оставаться воздухом;
- остальные 23 позиции заполняются корпусами.

Поддерживается приём маны Botania:

- лучами Mana Spreader;
- через Spark над контроллером;
- из ближайшего отдающего Mana Pool.

Улучшения:

- скорость I–V;
- добыча I–IX;
- генерация I–III.

## Теплица Botania

Добавлены:

- слот цветка;
- 3 слота модулей;
- 6 слотов топлива;
- бак воды/лавы;
- внутренний буфер маны;
- передача маны в соседний Mana Pool;
- Endoflame, Hydroangeas, Gourmaryllis, Entropinnyum, Thermalily и Spectrolus;
- модули Economy, Efficiency, Speed, Infinite Day, Infinite Night и Infinite Lava.

## Перенесённые предметы

Текущие партии включают:

- мета-ваджру;
- снежную пушку;
- топор черепов;
- электрические мечи нескольких уровней;
- энергетическую еду I–IV;
- иридиевый, квантовый и предельный ветророторы.

## Сборка

```bash
gradle build
```

Готовый JAR создаётся в `build/libs/`.

## Правило разработки

Изменения сначала попадают в отдельную ветку и черновой PR. В `main` они сливаются только после успешной GitHub Actions сборки и проверки непосредственно в игре.

# MetaTech Reborn — Forge 1.20.1

Современный порт машин и предметов из старых `MetaAdvanced`, `MetaThaumcraft`, `Greenhouses` и связанных аддонов для Minecraft 1.20.1 Forge.

## Текущая разработка

Рабочая ветка: `agent/0.5.5-unified-ae2`

Черновой PR: `#6`

Цель ветки — отказаться от отдельного JAR `AE2 Molecular Assembler Plus` и перенести экстремальный молекулярный сборщик и терминал шаблонов непосредственно в **MetaTech Reborn**.

> Важно: ветка экспериментальная. Успешная компиляция не заменяет проверку механизмов непосредственно в игре.

## Исправленное количество шаблонов

Правильный итоговый предел — **36 шаблонов**.

- без улучшения: **9** слотов шаблонов;
- улучшение ёмкости добавляет: **27** слотов;
- итог: **9 + 27 = 36** шаблонов.

Ранее упоминавшиеся пределы 28 и 30 больше не используются.

## Нативная система шаблонов 9×9

В MetaTech Reborn добавлены:

- пустой шаблон 9×9;
- закодированный шаблон 9×9;
- собственный NBT-формат шаблона;
- хранение всей сетки из 81 позиции и результата в одном предмете;
- внутренний банк молекулярного сборщика на 36 позиций;
- 9 активных позиций по умолчанию;
- улучшение, открывающее ещё 27 позиций;
- сохранение банка и улучшения через NBT;
- выбор сохранённого шаблона по результату задания и фактически переданным ингредиентам AE2;
- старый режим ручной фиксации рецепта для совместимости существующих миров.

### Терминал шаблонов 9×9

Добавлен отдельный блок `extreme_pattern_encoder`:

1. Выложите рецепт в сетку 9×9.
2. Поместите пустой шаблон в левый служебный слот.
3. Нажмите кнопку кодирования.
4. Заберите готовый закодированный шаблон из выходного слота.
5. Установите его в банк молекулярного сборщика.

Терминал проверяет рецепты Re-Avaritia и собственные рецепты MetaTech. Ингредиенты в сетке при кодировании не расходуются. Кнопка очистки возвращает предметы игроку.

Пока не перенесены:

- перенос рецепта из JEI одним нажатием;
- прокрутка страниц банка вместо одновременного показа всех 36 слотов;
- автоматическая миграция шаблонов из старого отдельного аддона.

## Один JAR

В ветке `agent/0.5.5-unified-ae2` удалены:

- зависимость от `AE2 Molecular Assembler Plus`;
- копирование второго JAR в GitHub Actions;
- отдельный архив аддона.

GitHub Actions теперь публикует только один файл MetaTech Reborn. Отдельно по-прежнему устанавливаются обязательные базовые моды: Forge, AE2, Botania и Re-Avaritia.

## Молекулярный сборщик 9×9

- поддерживает рецепты Re-Avaritia `crafting_table_recipe`, включая shaped и shapeless;
- имеет сетку 9×9, выход, FE, прогресс и NBT-сохранение;
- реализует интерфейс AE2 `ICraftingMachine`;
- принимает задания от Pattern Provider;
- выбирает подходящий закодированный шаблон из активной части банка;
- использует 9 или 36 слотов в зависимости от улучшения;
- реальные затраты FE исправлены.

## Объединитель нейтрония

- девять независимых входов;
- поддержка обычного, плотного, более плотного и максимально плотного нейтронного сборщика Re-Avaritia;
- резервные рецепты при сбое загрузки датапака;
- приём FE кабелями и заряженными предметами;
- отдельные индикаторы состояния каждого процесса;
- улучшения скорости, энергоэффективности и выхода.

## Мана-бур

Многоблочная структура 3×3×3:

- контроллер расположен в центре внешней стенки;
- ядро находится за контроллером;
- сопло находится над ядром;
- блок над контроллером должен оставаться воздухом;
- остальные 23 позиции заполняются корпусами.

Поддерживается приём маны Botania:

- лучами Mana Spreader;
- через Spark над контроллером;
- из ближайшего отдающего Mana Pool.

Улучшения:

- скорость I–V;
- добыча I–IX;
- генерация I–III.

## Теплица Botania

Добавлены:

- слот цветка;
- 3 слота модулей;
- 6 слотов топлива;
- бак воды/лавы;
- внутренний буфер маны;
- передача маны в соседний Mana Pool;
- Endoflame, Hydroangeas, Gourmaryllis, Entropinnyum, Thermalily и Spectrolus;
- модули Economy, Efficiency, Speed, Infinite Day, Infinite Night и Infinite Lava.

## Перенесённые предметы

Текущие партии включают:

- мета-ваджру;
- снежную пушку;
- топор черепов;
- электрические мечи нескольких уровней;
- энергетическую еду I–IV;
- иридиевый, квантовый и предельный ветророторы.

```bash
gradle build
```

Готовый JAR создаётся в `build/libs/`.

## Правило разработки

Изменения сначала попадают в отдельную ветку и черновой PR. В `main` они сливаются только после успешной GitHub Actions сборки и проверки непосредственно в игре.

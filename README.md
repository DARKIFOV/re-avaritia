# MetaTech Reborn — Forge 1.20.1

Порт выбранных машин и предметов из старых модов на Minecraft 1.20.1 Forge.

## Точный объём проекта

В актуальной разработке остаются только:

1. **Теплица Botania**
   - слот цветка;
   - 3 слота модулей;
   - 6 слотов топлива;
   - бак воды или лавы;
   - внутренний буфер маны;
   - Endoflame, Hydroangeas, Gourmaryllis, Entropinnyum, Thermalily и Spectrolus;
   - Economy I–III, Efficiency I–III, Speed I–III;
   - Infinite Day, Infinite Night и Infinite Lava.

2. **Мана-бур**
   - многоблочная структура 3×3×3;
   - приём маны от Mana Spreader, Spark и отдающего Mana Pool;
   - модуль добычи;
   - улучшения скорости I–V, добычи I–IX и генерации I–III;
   - выбранный пользователем комплект текстур.

3. **Экстремальный молекулярный сборщик 9×9**
   - сетка рецепта 9×9;
   - интеграция с AE2 Pattern Provider;
   - один JAR без отдельного внешнего аддона;
   - внутренний банк экстремальных шаблонов.

4. **Шаблоны и терминал 9×9**
   - пустой шаблон;
   - закодированный шаблон с сохранением 81 позиции и результата в NBT;
   - терминал кодирования;
   - 9 слотов без улучшения;
   - улучшение добавляет 27 слотов;
   - итог: **9 + 27 = 36 шаблонов**.

## Удалено из проекта

Следующие ранее добавленные или нарисованные системы полностью исключены из актуальной сборки:

- ME-импорт маны и ME-экспорт маны;
- ветророторы;
- объединитель нейтрония;
- мета-ваджра;
- снежная пушка;
- топор черепов;
- электрические мечи;
- энергетическая еда;
- остальные предметы вне точного объёма выше.

## Доработка оставшихся предметов

- реальные пределы уровней улучшений;
- отдельная редкость предметов;
- зачарованный блеск максимальных и специальных модулей;
- подсказки с уровнем и фактическим эффектом;
- имя закодированного шаблона по результату рецепта;
- явное описание полной сетки 9×9 и расчёта `9 + 27 = 36`.

## Текстуры

Теплица использует выбранный четвёртый вариант: тёмный livingrock, бронзовые крепления, бирюзовые мана-линии, мох и стеклянная камера.

Мана-бур использует livingrock-серый корпус, livingwood/бронзовые крепления, бирюзовые линии, зелёно-бирюзовое ядро и фиолетовые иконки модулей.

## Сборка

```bash
gradle build
```

Готовый JAR создаётся в `build/libs/`.

Успешная компиляция не заменяет проверку машин непосредственно в игре.

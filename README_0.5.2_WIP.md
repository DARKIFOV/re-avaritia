# MetaTech Reborn 0.5.2 — рабочая тестовая сборка

## Что добавлено

- первый набор предметов MetaAdvanced/LoliEnergistics: мета-ваджра, снежная пушка, топор черепа и линейка электрических мечей;
- собственное хранение энергии и переключаемый активный режим электрических мечей;
- подготовлена интеграция с экстремальным молекулярным сборщиком и терминалом кодирования шаблонов 9×9;
- GitHub Actions собирает основной мод и проверенный сопутствующий JAR терминала/сборщика.

## Установка тестовой сборки

Из архива GitHub Actions нужно поместить в папку `mods` оба файла:

1. `metatech_reborn-0.5.2-items-textures.jar`;
2. `AE2-Molecular-Assembler-Plus-1.20.1-1.0.0.jar`.

Также требуются Minecraft 1.20.1, Forge 47.x, Applied Energistics 2 15.x и зависимости текущей сборки MetaTech Reborn.

## Важные ограничения

- это рабочая версия, а не стабильный релиз;
- компиляция обоих JAR проверена GitHub Actions;
- работа непосредственно в игре ещё не подтверждена;
- сопутствующий JAR версии 1.0.0 реализует терминал шаблонов 9×9 и экстремальный сборщик, но его поддержка рецептов Re-Avaritia должна быть дополнительно проверена и при необходимости заменена прямой интеграцией в MetaTech Reborn;
- новые предметные текстуры ещё не возвращены в итоговый ресурсный пакет, поэтому возможны отсутствующие модели/текстуры.

## Следующий этап прямого переноса

В MetaTech Reborn должны быть перенесены только необходимые части исходного MIT-проекта AE2 Molecular Assembler Plus:

- кодирование и декодирование одного полного шаблона 9×9;
- терминал кодирования шаблонов;
- передача ингредиентов через AE2 Pattern Provider;
- экстремальный молекулярный сборщик;
- поиск рецептов Re-Avaritia через RecipeManager/API;
- JEI-перенос рецепта 9×9;
- собственная русская локализация и текстуры MetaTech Reborn.

При прямом переносе не следует добавлять необязательные части, связанные с Draconic Evolution, Mekanism или AvaritiaNeo.

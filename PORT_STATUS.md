# Состояние переноса

## Перенесено из старого MetaAdvanced

- логика поиска экстремального рецепта;
- автоматическое потребление сетки 9x9;
- выдача результата;
- интеграция с внешней системой автокрафта;
- сохранение состояния машины.

## Изменения для Forge 1.20.1

- `TileEntity` заменён на `BlockEntity`;
- старые AE2-интерфейсы заменены стандартным `ForgeCapabilities.ITEM_HANDLER`;
- рецепты Re-Avaritia берутся из публичного `CRAFTING_TABLE_RECIPE`;
- энергия реализована через `ForgeCapabilities.ENERGY`;
- GUI переписан на `AbstractContainerMenu` и `AbstractContainerScreen`;
- данные сохраняются в `CompoundTag`;
- optional-зависимость вынесена в отдельный класс `AvaritiaIntegration`;
- добавлена фиксация рецепта для правильной раскладки ингредиентов Pattern Provider.

## Проверки

- все JSON-файлы проходят синтаксический разбор;
- Java-файлы проходят синтаксический этап `javac`;
- имена и сигнатуры Re-Avaritia API сверены с JAR 1.4.1 и веткой `forge/1.20.1`;
- полноценная Gradle-сборка в текущем окружении не выполнялась, поскольку среда не содержит Gradle/ForgeGradle-кэша и не разрешает загрузку Gradle ZIP.


## MVP 2 — объединитель нейтрония

- перенесены 9 независимых входных модулей-сборщиков;
- каждый модуль имеет собственный прогресс, как в версии 1.7.10;
- сборщики не расходуются;
- добавлен выходной буфер на 40 слотов;
- добавлены FE, NBT-сохранение, автоподача/автовывод и JEI;
- соответствие сборщика, результата, времени и FE/t задаётся JSON-рецептами;
- добавлены готовые рецепты для четырёх сборщиков Re-Avaritia 1.20.1.

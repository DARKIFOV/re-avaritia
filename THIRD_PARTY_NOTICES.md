# Third-party components

## AE2 Molecular Assembler Plus

MetaTech Reborn 0.5.2 bundles the Minecraft 1.20.1 Forge build of **AE2 Molecular Assembler Plus 1.0.0** as a Forge Jar-in-Jar dependency.

- Project: `Gasai2225/AE2-Molecular-Assembler-Plus`
- Bundled mod id: `ccapplied`
- Features used: Extreme Molecular Assembler, Extreme Pattern Encoding Terminal, encoded 9×9 patterns and JEI recipe transfer.
- License: MIT. The original license and metadata remain inside the nested mod JAR.

The bundled component is not renamed or presented as original MetaTech Reborn code.

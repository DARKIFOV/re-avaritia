# Third-party components

MetaTech Reborn does **not** bundle `AE2 Molecular Assembler Plus` or another external gameplay mod inside its JAR.

The current native implementation uses the public APIs and runtime installations of:

- Applied Energistics 2;
- Botania;
- Re-Avaritia;
- Minecraft Forge;
- JEI, when installed.

Their code and assets are not repackaged into MetaTech Reborn. Users install the required dependency mods separately under their own licenses.

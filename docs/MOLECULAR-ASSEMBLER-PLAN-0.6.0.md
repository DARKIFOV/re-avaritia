# Молекулярный сборщик 9×9 — план 0.6.0

Основа поведения: промышленная схема LoliEnergistics — встроенный банк рецептов, атомарная приёмка задания и параллельная автоматизация — переписанная под официальный API Applied Energistics 2 для Forge 1.20.1. `ExtremeAutoCrafter` не используется.

## Реализовано

- [x] сетка крафта 9×9;
- [x] 9 встроенных шаблонов без улучшения;
- [x] 36 итоговых слотов с улучшением ёмкости;
- [x] блокировка снятия улучшения при занятых дополнительных слотах;
- [x] публикация внутренних шаблонов в ME-сеть через `ICraftingProvider`;
- [x] собственный управляемый AE2-узел, канал и подключение со всех сторон;
- [x] приём полного набора входов атомарно;
- [x] очистка `KeyCounter` только после успешной приёмки задания;
- [x] возврат результата непосредственно в ME-хранилище;
- [x] локальный ручной режим и режим AE2;
- [x] сохранение задания, входов, выхода, энергии, прогресса, банка шаблонов и AE2-узла в NBT;
- [x] безопасная работа при отсутствии AE2;
- [x] восстановление сборки ресурсов без повреждённых base64-фрагментов.

# Молекулярный сборщик 9×9 — план 0.6.0

Основа поведения: промышленная схема LoliEnergistics (встроенный банк рецептов, атомарная приёмка задания, параллельная автоматизация), переписанная под официальный API Applied Energistics 2 для Forge 1.20.1.

Целевые требования:

- сетка крафта 9×9;
- 9 встроенных шаблонов без улучшения;
- 28 шаблонов с улучшением ёмкости;
- блокировка снятия улучшения при занятых дополнительных слотах;
- публикация внутренних шаблонов в ME-сеть через `ICraftingProvider`;
- приём полного набора входов атомарно;
- возврат результата в ME-сеть без дюпов и потерь;
- локальный ручной режим и режим AE2;
- сохранение задания, входов, выхода, энергии и прогресса в NBT;
- безопасная работа при отсутствии AE2.

# Молекулярный сборщик 9×9 — план 0.6.0

Основа поведения: промышленная схема LoliEnergistics — встроенный банк рецептов, атомарная приёмка задания, блокировка активной операции и безопасный выходной буфер — переписанная под официальный API Applied Energistics 2 для Forge 1.20.1.

Целевые требования:

- сетка крафта 9×9;
- 9 встроенных шаблонов без улучшения;
- улучшение добавляет 27 слотов;
- итоговая ёмкость — **36 шаблонов**;
- блокировка снятия улучшения при занятых дополнительных слотах;
- публикация внутренних шаблонов в ME-сеть через `ICraftingProvider`;
- приём полного набора входов атомарно;
- возврат результата и контейнеров в ME-сеть без дюпов и потерь;
- локальный ручной режим и режим AE2;
- сохранение задания, входов, выхода, энергии, узла AE2 и прогресса в NBT;
- продолжение незавершённой операции после загрузки мира;
- безопасная остановка при заполненной или отключённой ME-сети;
- безопасная работа при отсутствии AE2 без загрузки его классов.

Серверные методы в предоставленном `LoliEnergistics-1.7.10-client.jar` заменены заглушками. Поэтому недостающая серверная часть восстанавливается по сохранённой структуре классов, контейнерам, NBT-полям, выходному буферу и поведению API, а не выдаётся за дословно извлечённый код.

# MetaTech Reborn 0.6.80

## Поддержка MultiBuilder Tool

- Добавлена совместимость с `MultiBuilderTool-1.20.1-1.0.27` (`modId=mbtool`).
- В JAR включается структура `data/metatech_reborn/mbtool_structures/mana_drill.nbt`.
- Мана-бур появляется в списке доступных конструкций MultiBuilder Tool как «Мана-бур MetaTech Reborn».
- Схема содержит полный мультиблок 3×3×3: контроллер, ядро, сопло, 23 корпуса и обязательную воздушную ячейку над контроллером.
- Структура может вращаться инструментом по четырём горизонтальным направлениям; свойства `facing` вращаются самим MultiBuilder Tool.
- После размещения штатная проверка MetaTech Reborn собирает бур и включает его единую визуальную модель.
- MultiBuilder Tool остаётся необязательной зависимостью: MetaTech Reborn запускается без него.

## Ресурсы

- Удалён последний этап сборки, который повторно заменял одобренные текстуры упрощённым набором 16×16.
- Очистка GUI и ранее одобренные ресурсы продолжают устанавливаться до упаковки JAR.

## Проверка

Необходимо проверить в игре:

1. наличие мана-бура в галерее MultiBuilder Tool;
2. предпросмотр структуры и подсчёт необходимых блоков;
3. поворот на 0°, 90°, 180° и 270°;
4. размещение контроллера, ядра, сопла и 23 корпусов;
5. автоматическое включение единой модели после завершения строительства;
6. возврат отдельных моделей при разрушении любой части.

# Final 0.6.77 asset overlay

The final resource overlay contains 44 approved Minecraft 16×16 textures for:

- standard and advanced Luck Converters;
- Extreme Pattern Encoder and pattern items;
- Greenhouse block faces and modules;
- Neutronium Combiner block faces and upgrades.

The overlay is reconstructed during every Gradle build from a compact shared palette. It deliberately excludes generated GUI concept sheets and does not replace Luck Converter module or speed-upgrade textures.

Validation is performed by GitHub Actions together with all packaged PNG and JSON resources.

# MetaTech Reborn 0.6.78

## Единая визуальная модель мана-бура

После успешной сборки мультиблока 3×3×3 мана-бур теперь отображается как одна цельная машина.

Реализация сохраняет безопасную многоблочную механику:

- контроллер, 23 блока корпуса, ядро и сопло физически остаются в мире;
- сохраняются коллизии, прочность, разрушение и выпадение отдельных блоков;
- обычные модели частей скрываются только в собранном состоянии;
- контроллер отрисовывает внешние поверхности всей конструкции одним `BlockEntityRenderer`;
- внутренние грани не рисуются, поэтому внутри структуры нет наложения одинаковых поверхностей;
- направление модели определяется ориентацией контроллера;
- поддерживается обычное и старое зеркальное направление сборки;
- при разрушении или замене любой части цельная модель отключается, а оставшиеся блоки снова становятся видимыми;
- при повторной сборке единая модель включается автоматически.

Механика добычи, мана, рецепты, улучшения, инвентарь и 81 выходной слот не изменялись.

## Технические изменения

- добавлено состояние `formed` для корпуса, ядра и сопла;
- контроллер получил состояния `formed` и `reversed`;
- добавлен `ManaDrillPartBlock`;
- добавлен клиентский `ManaDrillRenderer`;
- структура синхронизирует визуальное состояние всех своих частей;
- изменения частей инициируют внеочередную проверку ближайшего контроллера;
- собранные части используют пустую baked-модель, сохраняя физическую форму блока.

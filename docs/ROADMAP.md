# Roadmap MetaTech Reborn

## Обязательный игровой регрессионный тест

- [ ] Запуск Minecraft Forge 1.20.1 со сборкой из `main`.
- [ ] Проверка загрузки без дублирующего JAR.
- [ ] Проверка всех сторон обычного преобразователя удачи.
- [ ] Проверка всех сторон продвинутого преобразователя удачи.
- [ ] Проверка теплицы, объединителя нейтрония и кодировщика в мире.
- [ ] Проверка GUI при масштабах интерфейса 1, 2, 3 и Auto.

## Теплица

- [ ] Четыре одновременно установленных модуля.
- [ ] Стак из 16 одинаковых цветков.
- [ ] Работа с одним цветком и с 16 цветками.
- [ ] Бесконечная вода без расходования жидкости.
- [ ] Бесконечная лава без расходования жидкости.
- [ ] Бесконечный день и ночь.
- [ ] Уровни скорости, эффективности и экономии I–III.
- [ ] Сохранение инвентаря и жидкости после перезапуска мира.

## Re:Avaritia и JEI

- [ ] Перенос скалкового рецепта 3×3.
- [ ] Перенос адского рецепта 5×5.
- [ ] Перенос рецепта Края 7×7.
- [ ] Перенос экстремального рецепта 9×9.
- [ ] Проверка shaped и shapeless рецептов.
- [ ] Проверка пустых ячеек вокруг уменьшенной сетки.
- [ ] Проверка отказа при лишнем предмете вне активной сетки.

# Проверка MetaTech Reborn 0.5.5 unified AE2

## Установка

В папке `mods` должен находиться только один JAR MetaTech Reborn:

- `metatech_reborn-0.5.5-unified-ae2-WIP.jar`

Старый `AE2-Molecular-Assembler-Plus` для этой ветки удалить.

Обязательные зависимости:

- Forge 47.4.22;
- Minecraft 1.20.1;
- Java 17;
- Applied Energistics 2 15.4.x;
- Botania 1.20.1-454+;
- Re-Avaritia 1.4.1.

## Терминал шаблонов 9×9

1. Установить терминал шаблонов 9×9.
2. Открыть GUI.
3. Выложить действующий рецепт Re-Avaritia в сетку 9×9.
4. Положить пустой шаблон 9×9 в служебный слот.
5. Нажать «Кодировать».
6. Проверить появление закодированного шаблона.
7. Навести курсор и проверить отображение результата и количества заполненных позиций.
8. Нажать «Очистить» и проверить возврат предметов игроку.

## Банк молекулярного сборщика

1. Без улучшения проверить доступность первых 9 слотов.
2. Установить улучшение ёмкости.
3. Проверить доступность всех 36 слотов.
4. Заполнить несколько слотов разными шаблонами.
5. Перезайти в мир и проверить сохранение шаблонов через NBT.
6. Снять улучшение и проверить, что дополнительные шаблоны сохраняются, но не выбираются машиной.
7. Вернуть улучшение и проверить повторную доступность позиций 10–36.

## AE2 Pattern Provider

1. Установить Pattern Provider вплотную к молекулярному сборщику.
2. Добавить в банк сборщика закодированный шаблон требуемого результата.
3. Запустить автокрафт результата из терминала AE2.
4. Проверить выбор правильного шаблона.
5. Проверить раскладку всех 81 позиций.
6. Проверить расход FE.
7. Проверить возврат результата в сеть AE2.
8. Повторить с двумя шаблонами, содержащими похожие ингредиенты, но разные результаты.

## Регрессия машин

Дополнительно проверить:

- поступление маны в мана-бур лучом Mana Spreader;
- поступление маны через Spark;
- формирование структуры 3×3×3;
- девять процессов объединителя нейтрония;
- приём FE объединителем;
- работу теплиц с шестью поддерживаемыми цветами Botania.

При ошибке приложить:

- `logs/latest.log`;
- скриншот GUI;
- список версий модов;
- описание последовательности действий до ошибки.
